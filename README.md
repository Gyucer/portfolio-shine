# Portfolio Shine

Create a polished, responsive personal portfolio website using the attached CV as the source of truth. Extract the CV content and present it clearly with an engaging modern design. Include hero/about, experience, education, skills, projects or highlights where supported by the CV, and contact/social links. Make the copy professional and preserve the CV's language appropriately. Do not claim it is a Next.js project; build it as a Lovable web app.

This project was built with [Lovable](https://lovable.dev).
